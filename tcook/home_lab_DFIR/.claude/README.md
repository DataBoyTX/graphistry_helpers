# .claude Workspace - DFIR Attack & Defend Lab

This folder contains lightweight, persistent state files for building and maintaining a DFIR (Digital Forensics & Incident Response) Attack & Defend Home Lab.

## Project Overview
Build a simulated yet realistic enterprise environment for:
- Executing real-world attack techniques
- Capturing logs and telemetry
- Conducting Digital Forensics and Incident Response (DFIR)

## Suggested Operating Practice
- Read SYSTEM.md first for operational guidelines
- Check SUMMARY.md for current project state and progress
- Use PLAN.md to maintain direction through lab build phases
- Only execute tasks listed in TODO.md → Now
- Record architectural choices in DECISIONS.md
- Keep CONTEXT.md updated as assumptions/constraints change
- Reference TOOLS.md for available defensive and offensive tooling
